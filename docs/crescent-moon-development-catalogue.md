# Crescent Moon development catalogue

The six Crescent Moon chandelier examples are served only as `demoItems` by `/api/catalogue` on the development Vercel hostname and local development. They are not stored as supplier or product records in Supabase. The production domain does not receive these entries.

Each entry is marked `demoOnly`. The customer catalogue displays a non-bookable label and blocks basket actions. The server's live catalogue loader remains the source for order quotes, availability, and automatic AI visualiser product matching. These examples stay excluded from booking and availability. On unrestricted development looks, the customer can explicitly select one chandelier as a visual reference; the server sends its primary photo, matched additional views, name and dimensions to the image edit API without making it orderable. The choice is recorded in the look report and shown separately from bookable pieces. Refinements keep the selected chandelier through the parent rendered image and resend the original matched product reference photos. See crescent-moon-photo-reference-library-2026-11-05.md for the full source inventory and unconfirmed photo decisions. This uses reference inputs, not model fine-tuning.

Four products have illustrative one-day totals, itemised into daily hire, delivery/setup/collection, and refundable damage deposit. The examples assume VAT included and are not supplier quotes. The French Crystal Empire 105 and Vintage Necklace Empire 180 show price on request. Printed brochure stock is shown only as a specification note and is explicitly not current availability.

Before turning any of these into real listings, confirm with Crescent Moon: product/model/photo pairing, current specifications and stock, one-day hire rates, delivery/setup/collection charges, deposit and damage terms, VAT treatment, delivery coverage, venue access requirements, date-specific availability, and permission to publish the supplied photos and use them as AI visualiser references.
